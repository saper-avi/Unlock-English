# Карта учебников и интерактивной адаптации 0.4

Исходные учебники — два предоставленных пользователем издания Insight Student's Book (2014), по 166 PDF-страниц. Повторная копия Intermediate не создаёт третий курс.

На всех страницах доступен оригинал. Таблица ниже показывает **добавленный интерактивный материал**, а не полный объём исходных упражнений. Русские переводы, тренировочные вопросы и речевые фразы созданы для приложения.

Названия юнитов/разделов сохранены. Уровни — ориентиры приложения, не заверенная издателем шкала для каждой страницы.

## Чего не хватает для полного поупражненческого курса

Оригинальные CD/DVD и официальный ключ не были загружены. Остальные исходные задания пока выполняются по странице с заметками; автоматическая проверка не притворяется доступной. Отобранный словарь не охватывает все слова в reading-текстах. В каждой карточке доступны страницы-источники, а собственные слова можно добавлять вручную.

Тексты учебника сохранены как источники своего времени. Исторические данные/утверждения в них не выдаются за проверенную актуальную справку.
