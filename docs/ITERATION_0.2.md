# Итерация 0.2.0 · 25 октября 2026

## Реализовано

Продолжена извлечённая веб-часть: без новой дизайн-системы, без миграции на другой стек. Добавлены `web/feedback.js`, `web/ai-client.js` и `backend/`; доработаны `web/app.js`, `core.js`, `style.css`, `index.html`. Банк `content.js` сохранён без изменений.

Имеются экран ИИ-обратной связи, фиксированное демо, настройки токена личного backend, согласие на отправку, обработка устаревшего ответа после редактирования, история версий разбора, сопоставление тем с настоящими вопросами банка. AI-результат не добавляет XP и не открывает доступ к приложениям.

Backend: native Node.js HTTP/fetch, одна модель из конфигурации, OpenAI Responses API, `store:false`, строгий JSON Schema, собственная проверка ответа, аутентификация bearer-токеном, проверка Host/Origin, whitelist статических файлов, лимиты тела/текста/запросов, постоянный дневной счётчик, кэш только в RAM. Секрет генерируется при запуске и не входит в архив. Сервер предназначен только для личной локальной разработки.

Промпт направляет модель отделять стиль от ошибки, не выдумывать замечания, сохранять смысл и уровень, не выполнять инструкции из эссе. Это меры снижения риска, а не доказательство безошибочности или полной устойчивости модели к prompt injection. Валидация проверяет структуру и наличие фрагментов, не истинность лингвистических выводов.

Дополнительно исправлено дублирование одинаковых сохранённых текстов в один день. Формат прогресса `version:1` сохранён; новое поле `feedback` совместимо с его восстановлением. Старые копии не содержат token или API key.

## Не реализовано/не подтверждено

Новая Android-сборка, Gradle-проект и Java-исходники, живой вызов модели, качество оценок на корпусе эссе, реальная скорость API, публикация/деплой, многопользовательский backend, HTTPS-мобильная интеграция и тесты Android-сервиса. Старый APK не содержит новых функций.

Полноценный browser UI test не выполнен: Chromium запретил навигацию на localhost политикой `ERR_BLOCKED_BY_ADMINISTRATOR`. Ограничение не обходилось. Выполнены контроллерные тесты с DOM-заглушками, HTTP-тесты и чистые unit-тесты, но они не заменяют визуальную проверку.

В настройках примера выбрана модель GPT-5.4 Mini с reasoning effort none на основании документации, а не измерений качества или задержки. Без ключа работает локальный сценарий/фиксированное демо, а не настоящая ИИ-проверка.

## Важные границы следующего этапа

- Не запускать платные API-вызовы и не размещать сервер без осознанной настройки владельца.
- Не считать origin браузерного backend готовым для старого file:// WebView.
- Не считать API-токен владельца подходящей архитектурой для публичного многопользовательского приложения.
- Не менять Android-блокировку на основании текстов или оценок модели.
- Протестировать смену суток, перезапуски, смену часового пояса и миграцию реальных пользовательских данных при восстановлении Android.
- Исходная WebView-сборка и модуль focus пока сохранены как бинарники, не переписаны.
