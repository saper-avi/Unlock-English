# Unlock English — код из APK + задача для Codex

Это единая папка с **реальными исходными веб-файлами из присланного APK**, самим установочным файлом и обновлённым ТЗ. Веб-часть не переписана и не заменена новым макетом.

## Что внутри

| Путь | Содержимое |
| --- | --- |
| `web/` | Оригинальные HTML, CSS и JavaScript: интерфейс, 96 вопросов, 24 темы, учебная логика. |
| `original/Unlock-English-0.1.0.apk` | Присланный установочный файл без изменений. |
| `android-binary/` | Исходный скомпилированный Android-код (`classes.dex`), бинарный манифест и ресурсы. **Это не Java-исходники.** |
| `CODEX_HANDOFF.md` | Полное ТЗ: обучение, AI-проверка, ошибки, прогресс и добровольные ограничения приложений. |
| `AGENTS.md` | Инструкции для продолжения существующего проекта, а не создания нового с нуля. |
| `START_HERE.txt` | Готовый запрос для Codex. |
| `docs/` | Статус восстановления, контракт Android-моста, метаданные, контрольные суммы и результаты тестов. |
| `tests/` | 13 новых автоматических тестов учебного JavaScript-движка. |
| `tools/` | Локальный предпросмотр, проверка неизменности извлечённых файлов, команды для восстановления Java через установленный JADX. |

## Быстро открыть учебную часть

Нужен Node.js 18 или новее. Устанавливать npm-зависимости не требуется: здесь их нет.

Открой терминал в этой папке:

```sh
npm test
npm run preview
```

Открой адрес, который напечатает терминал: `http://127.0.0.1:4173`. Остановить сервер — Ctrl+C.

Это **предпросмотр существующей веб-части**, а не новая версия Android-приложения. В браузере работают локальная учебная логика и интерфейс; ограничения других приложений недоступны. В этой среде проверен запуск HTTP-сервера и Node-тесты, но браузерная проверка заблокирована политикой среды. Предпросмотр не объявляется проверенным UI-тестом.

Дополнительные проверки:

```sh
npm run check
python tools/verify-extraction.py
```

Последняя команда проверяет исходный APK и извлечённые файлы байт в байт. После осознанных изменений исходников несовпадение ожидаемо: манифест описывает именно исходную версию.

## Продолжить в Codex

Открой эту папку как проект и передай текст из `START_HERE.txt`. Сначала нужно восстановить собираемую Android-оболочку из APK, затем добавлять AI и остальные улучшения, сохраняя готовый интерфейс.

**Важная граница:** основной учебный код восстановлен полностью в том виде, в каком он находился в `assets/`. Java-исходников оболочки в пакете пока нет — есть только её байткод и справочные материалы для декомпиляции. Gradle-проект и новый APK здесь не создавались. Нельзя выдавать эту папку за полностью восстановленный и проверенный Android-проект.

Нативные компоненты определены по APK: пакет `app.unlockenglish`, `MainActivity`, `AppState`, `FocusAccessibilityService`; minSdk 26 и target SDK 35. Поведение сервиса на телефоне не проверялось.

ИИ-проверка пока остаётся задачей: имеющийся анализ письма выполняется локальными правилами, а кнопка «Для ChatGPT» подготавливает запрос для ручного копирования. API-ключей и серверной интеграции в архиве нет.

Перед заменой установленной версии экспортируй учебный прогресс. Исходный ключ подписи и прежняя конфигурация сборки не восстановлены; Codex должен отдельно проверить установку, подпись и перенос данных.
