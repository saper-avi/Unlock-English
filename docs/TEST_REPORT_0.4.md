# Unlock English 0.4 — фактические проверки

## Выполнено

- `npm test`: **92 / 92 passed**, 0 failed, 0 skipped. Проверены старый учебный движок, AI-контракт с фикстурами, HTTP-маршруты, валидация и новое книжное состояние/словарь/повторение/голосовой адаптер.
- `npm run check`: синтаксис JavaScript успешен.
- `python tests/books-browser.py`: **11 содержательных сценариев Chromium + отсутствие необработанных JS-ошибок** (12 записей отчёта). Настоящие DOM/CSS/страницы, viewport 390 и 1280, matching с ошибкой, интервальное повторение, письмо и оригинальный образец, поиск в приложениях к книге, сохранение и reduced motion. Native voice был явно подставленным адаптером; это не тест физического микрофона.
- Все **332 WebP** независимо декодированы Pillow, размер каждой страницы по ширине не менее 1499 px. Нулевых/битых файлов нет. Источники и контрольные суммы: `source-page-inventory-0.4.json`.
- `npm run build:preview`: создана полная папка 0.4, 332 изображения и текущие модули. Старый автономный HTML 0.3 перемещён в `tests/fixtures/` только для исторической регрессии.
- `native/build_android.py`: фактически создан `Unlock-English-0.4.0.apk`, 85 263 677 байт.
- `python tests/verify-apk-04.py`: **5 групп независимых статических проверок**. Контрольные суммы нового DEX; 2 новых класса / 16 тел методов / 3 JS-аннотации; декодирование инструкций, диапазоны регистров, аргументы вызовов и переходы; старые инструкции не изменены, снят только FINAL-флаг класса; проверены manifest/alias/version и наличие всех 332 страниц.
- `VerifyApkV2`: успешно проверены RSA/SHA-256 подпись v2, content digest и структура блока.
- `jarsigner -verify`: **jar verified**, v1 корректна. Ожидаемые предупреждения: self-signed certificate, нет доверенной публичной цепочки и timestamp. Для частного APK не требовался публичный CA. Сертификат действует до 2056 года.
- Сертификаты старого 0.3 APK и нового 0.4 извлечены из подписей и сравнены: **совпадают**. Пакет сохранён `app.unlockenglish.mobile`, versionCode повышен до 4.

## Не выполнено / не следует из проверок

- Нет реального Android/эмулятора: не подтверждены установка, прохождение ART verifier, запуск новой Activity, фактический TTS/распознавание, голосовые разрешения установленной службы и фокус на конкретной прошивке.
- Browser native mock проверяет интеграционный контракт, но не доказывает исправность микрофона/Android-сервиса.
- Нет живых платных запросов к OpenAI, AI в APK не подключён.
- Нет официальных аудиозаписей и ключей к учебникам. Полнота исходных страниц **не равна** полной автоматической проверке всех упражнений.
- 805 словарных карточек проверены по структуре/ссылкам; полноценная независимая лингвистическая экспертиза всех переводов и 80 новых вопросов не проводилась.
- Звук проверен программно, а не прослушиванием динамика реального телефона. Субъективная громкость зависит от устройства и системной громкости.

## Известные исправления, выявленные при проверке

- Восстановлен один повреждённый файл страницы Pre-Intermediate 64; после этого повторно декодированы все 332 страницы.
- Исправлен порядок аргументов книжного квиза при вызове прежнего движка.
- Индикатор навигации пересчитан с пяти на шесть разделов.
- Книжная кнопка примера открывает оригинальный Writing Guide, не текст-заглушку.
- Добавлена явная перезагрузка локальной страницы после регистрации Android JS-interface.
- Исправлены валидация пользовательских карточек и безопасная отмена/обработка повторных голосовых callbacks.

Логи приложены рядом. Данные среды не выдаются за пользовательское тестирование на телефоне.
