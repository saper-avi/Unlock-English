## Браузерные сценарии

1. Демо победы создаёт 30 временных частиц и планирует восемь звуковых тонов; XP и дневное состояние не меняются.
2. Плавное закрытие окна возвращает доступ к фону и освобождает inert.
3. Ошибочный ответ показывает объяснение и запускает два тона.
4. Правильный ответ показывает успех и запускает три тона.
5. Квиз с ошибкой и её последующим исправлением заканчивается отдельно от полной дневной миссии.
6. Квиз + письмо закрывают миссию: реальный бонус +20 XP, итоговое состояние 100 XP для тестового сценария, победный экран.
7. Отключение звука/анимации: новые голоса, частицы и анимации не запускаются.
8. Восстановление сохранённого состояния: настройки и XP остаются, поздравление и звук не повторяются.
9. Системный reduced motion, ширина 320px, закрытие Escape, отсутствие горизонтального переполнения.
10. Экран 1440px, переключение всех пяти разделов, удаление временных слепков страниц, доступность настроек.
11. Отсутствие необработанных JavaScript-ошибок во всех перечисленных сценариях.

## Ограничения проверки

В данной среде Chromium запрещает переход на `file://` и localhost (`ERR_BLOCKED_BY_ADMINISTRATOR`). Политики/ограничения браузера не отключались. Вместо навигации тест передаёт уже доступный автономный HTML в изолированный тестовый документ через `set_content`; localStorage/sessionStorage заменены хранилищем в памяти. Следовательно, это реальная проверка DOM, CSS, событий и Web Audio, но **не** end-to-end проверка загрузки сайта по URL или постоянного хранилища. HTTP-отдача файлов проверена отдельно Node-тестами.

Звуковые тесты проверяют создание/планирование/остановку реальных узлов Web Audio и mock-огибающие. Проверки на слух через телефонный динамик/наушники не было. Не измерялись FPS/нагрузка на реальном Android. Нет новой сборки Android, тестов AccessibilityService и живых запросов к модели. Исходный APK 0.1 не обновлён.
