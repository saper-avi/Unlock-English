# Отчёт проверок 0.2.0

Дата: 25 октября 2026. Среда: Linux, Node.js 22.16.0, Python 3.13.

## Выполнено

- `npm test`: **51 тест, 51 успешен, 0 пропущено, 0 ошибок**. Полный вывод в `test-output-0.2.txt`.
- `npm run check`: синтаксис JavaScript/CJS в web, backend, tools и tests корректен; вывод в `syntax-check-0.2.txt`.
- `python tools/verify-extraction.py`: SHA-256 оригинального APK, точных первоначальных assets в `original/web/` и нативных бинарников совпадают с предоставленным APK.
- `npm run build:preview`: создан единый автономный HTML-файл. Тест проверяет наличие и порядок 6 скриптов, их синтаксис, CSP-хеши, отсутствие внешних script/style и запрет сети.

## Покрытие

13 первоначальных регрессионных тестов учебного ядра и сохранённых оригиналов. Дополнительно: схема feedback, реальные фрагменты/Unicode/повторы, отказ от выдуманных оценок при статусе cannot_assess, корректный текст без ошибок, миграция/дедупликация истории, выбор настоящих вопросов по темам, идемпотентное сохранение текста.

Backend тестируется реальными локальными HTTP-запросами с фиктивным провайдером: авторизация, Host/Origin, Content-Type, длина тела, приватные пути, запросы с неверной структурой, квоты, объединение запросов, конфликт идентификаторов. Адаптер Responses API тестируется подставными ответами: успех, 401/403/429/5xx, усечение, отказ, невалидный JSON, несуществующие фрагменты, тайм-аут.

Проверка prompt injection удостоверяется, что вредоносный текст находится в отдельном недоверенном входе и модель не получает инструментов. Это НЕ результат атаки на живую модель и НЕ гарантия её полной устойчивости.

Семь UI-controller smoke-тестов выполняют текущий `app.js` в Node VM с минимальными DOM-заглушками. Проверены переключение экранов, демо без отправки/XP, отправка только после согласия, сохранение разбора без токена в прогрессе, устаревшие ответы после правки, HTML escaping, сохранение текста при ошибке API, переход в практику/историю. Они не проверяют layout, реальные браузерные события, WebView или accessibility.

- Полноценный тест в Chromium: попытка перехода на `http://127.0.0.1:4181/` завершилась `net::ERR_BLOCKED_BY_ADMINISTRATOR`. Ограничение не обходилось. Скриншотов успешного UI нет.
- Android build/install, Gradle/JADX-декомпиляция, устройство/эмулятор: необходимых инструментов нет. Сетевой доступ к Maven не разрешился по DNS. Нового APK нет.
- AccessibilityService, критичные системные исключения, перезагрузка/force-stop и аппаратные особенности Android не проверялись.
- Публикация, публичный HTTPS backend и многопользовательская инфраструктура не создавались.
