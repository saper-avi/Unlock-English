# Итерация 0.3 — движение и звук

## Реализовано

Существующие assets доработаны без смены стека. Учебные вопросы, core.js, feedback.js, ai-client.js и логика AI-провайдера не изменены. Новые `ux.js`/`motion.css` подключены в web/index.html, сборку автономного HTML и whitelist backend.

UX-модуль: Web Animations для появления/исчезания страниц, поочерёдного появления блоков, прогресс-бара и индикатора навигации. Отклик кнопок, переключателей, вариантов ответа. Выбор варианта теперь обновляет кнопки на месте, а не пересоздаёт весь вопрос. Модальные окна закрываются плавно; фон inert, фокус возвращается после закрытия. CSS/Web Animations не обязательны для работы.

Звуки: авторские процедурные сигналы на осцилляторах Web Audio с короткой огибающей. Верно — восходящие тоны; ошибка — мягкие нисходящие; итог квиза — три ноты; дневная миссия — короткий мотив с гармонией. Один контекст, последовательные события не накапливают звуки. При скрытии вкладки/закрытии окна, выключении звука или громкости 0 все запланированные голоса останавливаются. После восстановления страницы нет автозвука.

`C.completeDay` по-прежнему решает, завершён ли день; его результат используется для запуска праздника строго в пользовательском действии. Обе последовательности (квиз → письмо и письмо → квиз) покрыты тестами. Загрузка/импорт/фоновый tick могут синхронизировать состояние, но не запускают праздник. Демо вызывает только UI и аудио, не учебную логику.

Победный экран: фраза похвалы, одноразовое конфетти, галочка, бонус миссии +20 XP, настоящая серия занятий. В браузере не обещается открытие других приложений. Демо помечено и не показывает выдуманные начисления.

Настройки `unlock-english-ux-v1`: sound=true, volume=0.38, motion=true. Это отдельные локальные предпочтения; старый учебный ключ и формат сохранены. Системное уменьшение движения отключает анимации независимо от настройки приложения. Тексты, кнопки и результаты остаются доступными без звука/движения.
