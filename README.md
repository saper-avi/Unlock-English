# Unlock English 0.4 — книги, словарь и speaking

Android-приложение продолжает версию 0.3, а не заменяет её новым веб-макетом. Учебная база и прогресс прежнего приложения сохранены. Выпущенный APK: `Unlock-English-0.4.0.apk` (распространяется отдельно от архива исходников).

## Установка обновления

1. В версии 0.3 экспортируй резервную копию: **Прогресс → Экспорт**.
2. Открой APK 0.4 на Android и установи обновление поверх 0.3. Пакет `app.unlockenglish.mobile` и сертификат подписи совпадают; версия кода повышена до 4. **Не удаляй 0.3 ради обновления.** Сохранение данных при обновлении предусмотрено, но установка на реальный телефон в этой среде не проверена.
3. Открой новый раздел **Книги**. Выбери учебник, юнит и нужный формат практики.
4. Если установлена самая первая версия 0.1 с другим пакетом/подписью, используй экспорт/импорт; не считай её той же сборкой, что 0.3.

Android 8.0+ (minSdk 26), targetSdk 35. Исходная система добровольного фокуса сохранена, на устройстве повторно не тестировалась.

## Что добавлено

- **Два учебника целиком: 332 страницы, по 10 юнитов.** Сохранены исходные страницы, иллюстрации, reading, writing, Vocabulary insight, Review, Cumulative review, Vocabulary bank и Grammar reference & practice. Есть поиск по извлечённому тексту, масштабирование, заметки/ответы к странице и отметка изучения. Повторная копия Intermediate не дублируется.
- **805 словарных карточек:** 383 Pre-Intermediate и 422 Intermediate. У каждой есть юнит, русский перевод и страницы-источники. Карточки, сопоставление пар, активное воспроизведение слова, повторение с интервалами; можно добавить своё слово. Это не все слова книг: исходные тексты доступны полностью, а переведённый интерактивный словарь — отобранная часть. 120 неподтверждённых кандидатов исключены и записаны в `content/excluded-vocabulary.json`.
- **Matching:** пять однозначных пар, перемешанные колонки, повтор после ошибки, звуковой и анимированный отклик, честный результат первой попытки.
- **Speaking:** в каждом из 20 юнитов есть повторение фразы и свободный ответ — 40 режимов-заданий. Озвучка обычная/замедленная, системный ввод голосом, редактируемая расшифровка, сравнение слов с образцом, история. Сопоставление расшифровки — **не оценка фонетики или акцента**. Свободный ответ требует самопроверки; AI его автоматически не оценивает.
- **80 новых грамматических вопросов и 20 письменных тем.** Это собственная адаптация по грамматике, жанрам и разговорным функциям соответствующих юнитов, не официальный ключ издателя. Итого вместе с прежней базой: 176 вопросов и 44 темы письма. Кнопка примера в книжных темах открывает исходный Writing Guide, а не выдуманный образец.
- Дополнительные анимации карточек, успешных пар, результатов, прогресса и микрофона; более громкие синтезированные звуки. Громкость по умолчанию 62% вместо 38%, усиление сигнала увеличено; сохранённая громкость/тишина не перезаписывается. Системная громкость телефона не меняется. Настройка уменьшения движения имеет приоритет.

## Покрытие книг — важная граница

**Все 332 страницы включены. Не каждое исходное упражнение превращено в автоматически проверяемый квиз.** Для оставшихся упражнений есть исходная страница, поле ответа/заметки и самостоятельная работа. Полного официального ключа и записей CD/DVD в предоставленных файлах нет. Ответы на listening по отсутствующим записям не придуманы; TTS-озвучка слов не обозначается как оригинальное аудио учебника.

Русские переводы, тренировочные фразы, грамматические вопросы и новые письменные темы помечены как адаптация приложения. Структурные тесты не заменяют профессиональную лингвистическую вычитку. Полная постраничная сохранность не означает ручную проверку каждого упражнения и каждого возможного ответа.

**Уровни:** Pre-Intermediate — ориентировочный маршрут A2→B1, Intermediate — B1→B2. Внутри маршрута первые четыре юнита отмечены нижней ступенью, остальные — верхней. Это редакционная навигация приложения, не официальная сертификация CEFR этого издания и не диагностика пользователя. Перекрытие тем нормально; сложность конкретного упражнения может отличаться.

Материалы взяты из двух предоставленных пользователем PDF; имена авторов и издательские сведения сохранены на исходных страницах. Архив предназначен для продолжения этого личного проекта. Публичное распространение учебников и публикация в магазине приложений здесь не выполнялись.

## Speaking на телефоне

Голосовой ввод открывает **системный экран распознавания речи Android** после нажатия и согласия. Нужна установленная служба распознавания; её доступность, разрешения и офлайн-работа зависят от телефона. Служба может отправлять аудио своему провайдеру — это объяснено перед запуском. Само приложение сохраняет текст расшифровки, не записывает фоновый звук и не отправляет его на наш AI-backend.

Для озвучки нужна доступная английская TTS-модель. Если её нет, приложение сообщает об этом. Можно практиковаться без микрофона: ответить вслух, вписать текст и выполнить самопроверку. Такой режим явно отличён от распознавания голоса. Отсутствие голосовой службы не блокирует дневную миссию или телефон.

## Что работает без сети

Книги, словарь, matching, квизы, заметки, черновики, интервальное повторение, локальная самопроверка и эффекты. TTS/распознавание могут требовать подключения в зависимости от установленной системной службы. **ИИ-проверка в этом APK не подключена**; прежний backend сохранён в исходниках. Демо ИИ остаётся явно обозначенным демо.

Книжные тренировки дают ограниченные идемпотентные XP, но сами по себе **не обходят** основную ежедневную миссию и не отключают фокус. Основной сценарий по-прежнему управляется локальной учебной логикой.

## Запуск исходников на компьютере

Нужен Node.js 22.6+; npm-зависимостей нет.

```sh
npm start
# адрес сервер напечатает в терминале; обычно http://127.0.0.1:4173
npm test
npm run check
```

`npm run preview` запускает статический просмотр без AI-backend. `npm run build:preview` создаёт папку `dist/Unlock-English-0.4-preview` со всеми страницами; это не один HTML-файл. Для надёжного хранения используй постоянный адрес сервера. Подключение реального AI для локальной веб-версии описано в `docs/BACKEND_SETUP.md`; API-ключ только на сервере, API оплачивается отдельно. Не публикуй личный dev-сервер в интернет без отдельной защиты.

## Сборка Android и подпись

`native/build_android.py` использует восстановленную оболочку исходного APK, добавляет текущие assets и небольшой новый голосовой мост. Это **не полная Gradle-пересборка Java-исходников старого приложения**. У `MainActivity` снят только флаг FINAL; оригинальные инструкции не менялись. Новый `classes2.dex` создаётся `tools/voice_dex.py`; читаемый эквивалент — `native/CourseActivity.java` и `VoiceJob.java`.

Для сборки нужны Python, cryptography, Java JDK (`jarsigner`), а для проверки — `javac`/`java`. SDK Android этому упаковщику не требуется. Перед сборкой задай `UNLOCK_SIGN_DIR` — путь к **своей прежней папке `.signing` из личной резервной копии 0.3**. В этом архиве закрытого ключа/пароля нет.

```sh
npm run build:voice
# Linux/macOS, укажи реальную приватную папку:
UNLOCK_SIGN_DIR=/private/path/to/.signing npm run build:apk
python tests/verify-apk-04.py
javac native/VerifyApkV2.java
java -cp native VerifyApkV2 dist/Unlock-English-0.4.0.apk
jarsigner -verify dist/Unlock-English-0.4.0.apk
```

Без старого ключа упаковщик создаёт новый личный ключ: такой APK **не обновит** установленную 0.3. Не удаляй рабочее приложение для обхода несовпадения подписи. Не публикуй `.signing`, `.p12`, PEM закрытого ключа, пароль или `.env`.

## Проверки и ограничения

Актуальные отчёты: `docs/TEST_REPORT_0.4.md`, `docs/browser-checks-0.4.json`, `docs/apk-static-checks-0.4.json`, `docs/book-coverage.json`. Запуск на физическом Android/эмуляторе, реальный микрофон, динамик и фактический режим фокуса **не проверены**. Статическая проверка DEX/подписи не доказывает успешную загрузку ART на каждом телефоне.

Прогресс сохраняется в прежнем ключе `unlock-english-v1`, новый раздел — в `bookStudy`. Экспорт включает заметки и расшифровки. Существующий импорт принимает резервные копии до 2 МБ; это ограничение не расширено. Регулярно сохраняй резервную копию. Голосовые записи не входят в экспорт, потому что приложение их не хранит.

## Структура

```text
web/                 интерфейс, старая база, новые модули и 332 страницы
content/             адаптированные данные и исключённые кандидаты
tools/               генераторы данных, native DEX и инструменты проверки
native/              читаемый голосовой мост, classes2.dex, упаковщик, verifier
backend/             личный локальный AI-backend (не подключён в APK)
original/            неизменённый исходный APK 0.1 и его web-assets
android-binary/      восстановленные исходные бинарники
tests/               unit/HTTP/browser/статические APK-тесты
docs/                актуальные отчёты 0.4 и явно исторические документы
```

Копии старых отчётов 0.1–0.3 описывают прошлые версии, а не состояние 0.4. Для продолжения разработки сначала читай этот README и AGENTS.md.
