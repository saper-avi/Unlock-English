# Unlock English 0.4 — инструкции разработчику

Сначала прочитай README.md, docs/TEST_REPORT_0.4.md, docs/book-coverage.json и CODEX_HANDOFF.md. README 0.4 имеет приоритет над историческими отчётами.

- Продолжай существующий WebView-проект, не переписывай его с нуля. Сохрани 96 исходных вопросов, 24 исходные темы письма, ежедневную миссию, фокус, настройки и экспорт.
- В web/ находятся текущие модули: book-core.js, book-ui.js, book-speech.js, book-content.js, book-tasks.js, book-pages.js и все 332 страницы двух пользовательских PDF. original/web/ — исторические байтовые оригиналы.
- Не путай полную сохранность страниц с полной интерактивной адаптацией. 805 карточек, 80 новых грамматических вопросов, 20 новых письменных тем и 40 устных заданий — фактический объём адаптации. Официальных ключей и записей CD/DVD нет.
- Уровни A2→B1 и B1→B2 — редакционные ориентиры, не подтверждённая издателем сертификация первого издания. Не подменяй исходную терминологию и разделы общими темами.
- Для каждого добавления сохраняй происхождение: книга/юнит/PDF-страницы/тип адаптации. Не выдавай свои переводы, примеры и ответы за издательский ключ. Не добавляй выдуманные listening-ответы.
- Новая native-сборка существует. native/build_android.py перепаковывает исходную оболочку, снимая только FINAL у MainActivity и добавляя classes2.dex. Полной Gradle-реконструкции ещё нет. CourseActivity.java/VoiceJob.java — читаемый эквивалент нового моста.
- Сохраняй пакет app.unlockenglish.mobile и увеличивай versionCode при следующем обновлении. Приватный старый ключ предоставляется локально через UNLOCK_SIGN_DIR, не включается в ZIP/Git. Не генерируй молча другой ключ для якобы совместимого обновления.
- Тестируй фактическую Android-установку/ART/микрофон/фокус при доступном устройстве: 0.4 прошла лишь статические и изолированные браузерные проверки. Не называй mock реальным распознаванием.
- Расшифровка не равна оценке произношения. Микрофон только по явному действию и согласию. Не добавляй фоновую запись/чтение чужих экранов.
- ИИ и голос не управляют системной блокировкой. Нет сети/ключа/разрешений — остаётся безопасная локальная практика и экстренный выход.
- API-ключ только на backend; никаких секретов в APK. Не включай universal file access и не снимай CSP ради интеграции.
- Сохраняй идемпотентность XP, интервалов повторения, отправок, дневных наград. Книжный квиз не завершает основную миссию автоматически.
- Сохраняй русские объяснения, настройки громкости/тишины, reduced motion и отсутствие autoplay. Анимации не должны повторно начислять награды.
- npm test; npm run check; python tests/books-browser.py; после сборки python tests/verify-apk-04.py и проверки v1/v2. Для Python-тестов нужны отдельные зависимости.
- Реальные результаты, ошибки и ограничения записывай в docs. Не обещай тестирование на телефоне без него. Не публикуй пользовательские книги, приложение, приватный ключ или платную инфраструктуру без отдельного согласования.
