UNLOCK ENGLISH 0.4

УСТАНОВКА НА ТЕЛЕФОН
APK передан отдельно: Unlock-English-0.4.0.apk.
Сначала экспортируй прогресс в 0.3, затем установи обновление, не удаляя старое приложение.
Открой «Книги» → учебник → юнит → Matching / Слова / Speaking / Грамматика / Письмо / исходные страницы.

ИСХОДНИКИ НА КОМПЬЮТЕРЕ
Node.js 22.6+, команда npm start в папке с package.json.
Далее открой адрес из терминала. npm install не нужен.
npm test; npm run check.

Это не пустое ТЗ: код, контент двух книг и нативный голосовой мост находятся в архиве.
APK собран, но установка и микрофон на настоящем Android не проверены.
Полные книги доступны постранично; не все исходные упражнения автоматически оцениваются.
ИИ в APK не подключён. Оригинальные аудиотреки учебников не предоставлены.
